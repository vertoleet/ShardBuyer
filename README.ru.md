## ✨ Возможности

- **Категории** — у каждой категории своё настраиваемое меню. Либо одно меню, в котором страницы
  листаются по категориям (`menu-mode: PAGED`).
- **Умные цены** — задаёте только цены сырья, остальное плагин считает сам по рецептам сервера:
  - *упаковка* (9 сушёных ламинарий ⇄ блок) стоит ровно как предметы внутри;
  - *настоящий крафт* (поршень) дороже ингредиентов (`craft-multiplier`);
  - *переплавка* повышает цену (ламинария 2$ → сушёная 3$);
  - всегда берётся самый дешёвый рецепт, поэтому абузить нечего.
- **Зачарования** — своя цена у каждого зачарования и уровня; зачарованные книги, броня и
  инструменты стоят дороже, повреждённые — дешевле.
- **Прокачка** — за продажу дают очки, уровень повышает цены. Общий уровень, свой уровень в каждой
  категории или выключено. Прокачку можно отключить у отдельных категорий.
- **Динамический рынок** — чем больше все сдают предмет, тем ниже цена и очки. Со временем цена восстанавливается.
- **Эксклюзивы** — повышенная цена, но ограниченное количество; лимиты и случайная ротация обновляются по таймеру.
- **Меню продажи** — 54 слота: положил предметы и нажал кнопку или просто закрыл. Работает с
  зачарованными вещами, книгами и шалкерами.
- **Автопродажа** — включается для отдельных предметов, продаёт сразу при подборе (даже при полном
  инвентаре). Можно полностью отключить.
- **Цена в описании предметов** — видна только самому игроку, с его бонусами, обновляется при любом
  изменении инвентаря. Предметы на сервере **не меняются**, поэтому стакаются как обычно.
- **`/worth`** — все цены со страницами, сортировкой, фильтром по категориям и поиском.
- **Формат чисел** — `1,000` · `1 000` · `1.000` · `1000` или коротко `1k` `1m` `1b`.
- **6 языков** — English, Español, Русский, Українська, Português, Français.
  Названия предметов в чате показываются на языке клиента каждого игрока.
- **Настраивается всё** — сообщения, меню, звуки, названия команд и алиасы.
- Глобальный бустер цен, множители по правам, плейсхолдеры PlaceholderAPI.

## 📦 Требования

| | |
|---|---|
| Сервер | **Paper 1.20.4** (или форк), Java 17+ |
| Обязательно | [Vault](https://www.spigotmc.org/resources/vault.34315/) + любой плагин экономики (EssentialsX, CMI, …) |
| Рекомендуется | [ProtocolLib](https://github.com/dmulloy2/ProtocolLib/releases) **5.2.0+** — для цены в описании предметов |
| По желанию | [PlaceholderAPI](https://www.spigotmc.org/resources/placeholderapi.6245/) |

## 🚀 Установка

1. Скачайте `ShardBuyer-x.x.x.jar` в разделе [Releases](../../releases).
2. Положите его в `plugins/` вместе с Vault, плагином экономики и ProtocolLib.
3. Запустите сервер. В `plugins/ShardBuyer/config.yml` поставьте `language: ru`.
4. Настройте файлы и выполните `/shardbuyer reload`.

## 💬 Команды

Названия команд и алиасы задаются в `config.yml → commands` (ниже — по умолчанию).

| Команда | Описание |
|---|---|
| `/buyer [категория]` | открыть скупщика |
| `/buyer lore` · `autosell` · `level` · `exclusive` · `help` | цена в описании · автопродажа · уровень · эксклюзивы · помощь |
| `/sell` | меню продажи |
| `/sell hand` · `/sell all` | продать предмет в руке · весь инвентарь |
| `/worth` | список цен |
| `/worth hand` · `/worth lore` · `/worth <категория или текст>` | цена в руке · цена в описании · фильтр / поиск |
| `/shardbuyer reload` | перезагрузить файлы |
| `/shardbuyer setprice <цена> [предмет]` · `delprice [предмет]` | задать / убрать ручную цену |
| `/shardbuyer info` | разбор цены предмета в руке |
| `/shardbuyer points <игрок> <add\|set\|take> <кол-во> [категория]` | изменить очки |
| `/shardbuyer resetlevel <игрок>` | сбросить прокачку |
| `/shardbuyer market <reset\|info> [предмет]` | динамический рынок |
| `/shardbuyer exclusive reset` | обновить эксклюзивы |
| `/shardbuyer booster <множитель> <время>` · `booster stop` | глобальный бустер цен |
| `/shardbuyer dump` | выгрузить все итоговые цены в `computed-prices.yml` |

## 🔑 Права

| Право | По умолчанию | Описание |
|---|---|---|
| `shardbuyer.use` | все | открыть скупщика |
| `shardbuyer.sell` | все | меню продажи, `/sell hand` |
| `shardbuyer.sell.all` | все | `/sell all`, «продать весь инвентарь» |
| `shardbuyer.worth` | все | `/worth` |
| `shardbuyer.lore` | все | цена в описании предметов |
| `shardbuyer.autosell` | все | автопродажа |
| `shardbuyer.admin` | op | админ-команды |
| `shardbuyer.multiplier.<имя>` | — | множители цен из `config.yml → multipliers` |

## 📁 Файлы

| Файл | Что внутри |
|---|---|
| `config.yml` | язык, команды, режим меню, формат чисел, прокачка, рынок, автопродажа, цена в описании |
| `lang/<код>/messages.yml` | все сообщения |
| `lang/<код>/menus.yml` | все меню, названия и описания категорий |
| `categories.yml` | категории и их предметы |
| `prices.yml` | базовые цены и авторасчёт |
| `enchantments.yml` | цены зачарований |
| `exclusive.yml` | эксклюзивные предметы |
| `item-names.yml` | свои названия предметов (необязательно) |

Цвета: `&a`, HEX `&#C084FC` (градиенты `<gradient:#C084FC:#67E8F9>текст</gradient>` тоже поддерживаются).

**Свой язык:** скопируйте папку `lang/en` в `lang/<код>` (например, `lang/de`), переведите и
поставьте `language: de`.
